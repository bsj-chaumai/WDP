# 仕様：途中保存サーベイの再開・完了時のレコード更新

## 現状
途中保存したサーベイを再開して完了すると、`survey_response` に新規レコードが作成され、既存レコードと合わせて2件になる。

## 修正後

1. **途中保存リストから再開した場合**  
   既存レコードを上書きする（新規レコードは作らない）。

2. **新規で回答を完了した場合**  
   以前の途中保存レコードを途中保存リストから削除する。  
   ※DB側の該当レコードも削除する。

3. **途中保存レコードが複数ある状態で、いずれか1件から回答を完了した場合**  
   残りの途中保存レコードも無効化し、途中保存リストから削除する。  
   ※DB側の該当レコードも削除する。

4. **途中保存リストから再開し、途中で再度「途中保存」した場合**  
   既存レコードを上書きする。次回ログイン時も途中保存リストに残る。

## テスト観点

| # | 操作 | 期待結果 |
|---|------|----------|
| 1 | 途中保存リストから再開し、最後まで完了する | 既存レコードを上書き。完了後、当該レコードは途中保存リストから消える |
| 2 | 途中保存リストから再開し、途中で再度「途中保存」する | 新規レコードは作らず、既存レコードを上書き。次回ログイン時も途中保存リストに残る |
| 3 | 途中保存リストを使わず、新規開始して完了する | 完了レコードを新規作成。以前の途中保存レコードはリスト・DBから削除する |
| 4 | 途中保存レコードが複数ある状態で、いずれか1件から完了する | 完了した1件は上書き（または完了状態へ更新）。残りは無効化し、リスト・DBから削除する |
